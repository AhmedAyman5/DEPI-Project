# Shop Easy

A simple e-commerce store developed as part of the ITI summer training program. The main goal of the project is to provide users with an easy and fast shopping experience, featuring an interactive interface and essential features for any modern online store.

## Main Features

- Browse products in an organized and attractive way.
- Product details page for each item.
- Add products to the cart and manage the cart.
- Smooth and fast user experience built with modern technologies.
- Easy to customize and extend.

## Technologies Used

- **React.js**: For building a dynamic user interface (main code in `src/App.jsx` and `src/main.jsx`).
- **Vite**: For fast development and build process (`vite.config.js`).
- **JavaScript** & **CSS**: For building and styling pages and components.
- **Context API**: For global state management (`src/context` folder).
- **components folder**: Contains UI components such as products, cart, etc.
- **pages folder**: Contains different application pages like products, cart, etc.
- **utils folder**: Utility functions used throughout the app.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedcodexx/shop-easy.git
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the app locally:
   ```bash
   npm run dev
   ```
4. Open the local URL displayed in the terminal to try the app.
